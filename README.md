# ❄️ 桌面下雪 Snow Desktop

让你的 Windows 桌面下一场真正会“堆”的雪。

- 雪花 60 帧顺滑飘落
- 雪会堆在任务栏上方和每个窗口的顶边
- 关窗口、最小化、甩动窗口，上面的雪会哗地掉下来
- 鼠标划过积雪会把雪推开、溅起雪沫
- 雪量三档：小雪 / 中雪 / 大雪，托盘「雪量」切换
- 物理雪人：鼠标左键点一下就倒，三个雪球各自滚动，再单击雪球就地重新堆起来
- 雪人 6 套衣服：经典、圣诞老人、滑雪运动、国王、夏日度假、绅士，每 25 秒自动换，托盘「换衣服」手动换
- 履带推土机：积雪太厚自动出动，履带会转、排气管冒烟，推铲把雪顶起来往前撒，托盘「叫推土机」随时叫

> 演示视频：抖音搜索 **lixiansheng11.**

## 下载使用（不用装 Python）

1. 打开右侧 **Releases**，下载 `SnowDesktop.exe`
2. 双击运行；退出：右下角托盘雪人图标 → 退出
3. 杀毒软件可能误报（打包工具的通病），选择“允许运行”即可

## 从源码运行

```
pip install -r requirements.txt
python snow_desktop.py
```

需要 Windows 10/11、Python 3.10+，目前只支持主显示器。
